GETTING STARTED
===============

1. Clone and install:
   pnpm install

2. Start services:
   docker compose up -d
   pnpm db:dev

3. Run development:
   pnpm dev
   pnpm tunnel (in new terminal)

4. Configure webhook and play!

For detailed instructions, see:
  - QUICKSTART.md (fastest)
  - GETTING_STARTED.md (detailed)
  - START_HERE.md (navigation)
